# WhatsApp Integration Demo Script - 3 Minute Version

## Overview
Quick demo showcasing the most impressive capabilities: AI-powered image analysis and location sharing with Google Maps.

**Total Time**: 3 minutes  
**Prerequisites**: WhatsApp on phone, 1 demo image ready

---

## 0:00 - 0:30 | Opening (30 seconds)

**[Screen: Show your phone with WhatsApp open]**

**Say**:
"This is a live WhatsApp-Salesforce integration with Agentforce AI. Watch how it automatically processes images using GPT-4o vision and handles location sharing with Google Maps - all in real-time."

**Action**: Open WhatsApp conversation with the business number

**Type in WhatsApp**:
```
Hi! Show me what you can do
```

**[Screen: Show message sending and agent responding]**

**Say** (while waiting ~2 seconds):
"The message goes through webhook validation, creates records in Salesforce, and routes to our AI agent."

**Agent responds with**:
Welcome message offering to demo location, images, audio, and documents.

**Say**:
"The agent is conversational and guides users through each feature."

---

## 0:30 - 2:00 | Image Analysis Demo (90 seconds)

**Type in WhatsApp**:
```
Analyze an image for me
```

**Agent responds**:
Instructions on how to send an image.

**Say** (15 seconds):
"I'll send this product image. Behind the scenes, the system will:
- Download it to Salesforce Files
- Trigger a Flow that uses GPT-4o vision
- Analyze the image and send results back to the agent"

**Action**: 
- Tap + icon
- Select "Photo & Video"
- Send your prepared image (product, receipt, or interesting photo)

**[Screen: Split screen showing WhatsApp + Salesforce]**

**Say** (while processing ~5 seconds):
"This takes about 5 seconds - downloading the image, running AI vision analysis, and routing the results back."

**[Screen: Show in Salesforce - Files, WhatsApp_Media__c record, Logs]**

**Say** (20 seconds):
"Look - the image is now stored in Salesforce Files. Here's the media record showing it's downloaded and processed. The logs show each step of the pipeline."

**Agent responds with**:
Detailed AI analysis of the image content.

**[Screen: Back to WhatsApp showing agent response]**

**Say** (20 seconds):
"The agent received a complete description - objects, colors, text, context. This enables:
- Product identification in retail
- Damage assessment for insurance
- Receipt processing for expenses
- Visual troubleshooting in support

All automatic, all in real-time."

---

**Agent responds with**:
Location details and Google Maps link.

**[Screen: Show Salesforce - conversation record with all messages]**

**Say** (15 seconds):
"Everything is stored: the full conversation, media files, location data, complete audit trail. Zero manual intervention. This is WhatsApp Business API integrated with Salesforce Agentforce, AI vision, and intelligent automation."

## Video Recording Tips

### Camera Setup
- **Option 1**: Screen record phone + screen record Salesforce, edit side-by-side
- **Option 2**: Use phone mirroring software (QuickTime/Reflector) for live view
- **Option 3**: Film phone with camera, screen record Salesforce separately

### Timing Rehearsal
1. **Practice 3-4 times** to nail the timing
2. **Have screens ready**: Salesforce tabs open (Files, Logs, Messages)
3. **Test agent first**: Make sure it's responding quickly
4. **Prepare image**: Choose something visually interesting that will have a good AI description

### What to Pre-Open
- WhatsApp conversation
- Salesforce: WhatsApp_Log__c list view
- Salesforce: Files (Content tab ready)
- Salesforce: WhatsApp_Message__c list view

### Script Variations

**If you want to show 3 features in 3 minutes:**
- 30s intro
- 60s image analysis (keep this - most impressive)
- 45s location sharing
- 45s audio OR document (pick one)
- 30s close

**If agent responses are slow:**
- Fill time by explaining architecture
- Show Salesforce processing in real-time
- Talk about use cases

### Editing Notes
- **Speed up** waiting time (when message is processing)
- **Add text overlays** for key points
- **Highlight** important UI elements (red circle annotations)
- **Add background music** (keep it subtle)
- **Include timestamps** if posting online
